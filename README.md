# Night Vision Thermal Camera

Android camera app for low-light viewing on normal phone cameras.

Features:
- Night Vision mode: green low-light enhancement with gain and contrast controls.
- Thermal Style modes: Ironbow and Rainbow false-colour palettes made from visible-light brightness.
- White Hot, Black Hot and Edge Detect modes.
- Torch control, front/back camera switch, and external camera selection when Android exposes a USB/external camera.
- Capture processed frames to Pictures/NightVisionThermal.
- No native libraries, so the APK is suitable for 32-bit Android phones such as Infinix Smart 9.

Important limit: Thermal Style is not real thermal imaging. A normal phone camera cannot measure heat. Real thermal imaging needs an external LWIR sensor such as FLIR Lepton, PureThermal, FLIR One, or a similar USB thermal camera.
